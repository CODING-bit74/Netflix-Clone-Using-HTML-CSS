## About

This repository contains a pixel-perfect (or near pixel-perfect) static clone of the Netflix landing page. It focuses on layout, responsive behavior, and animations using modern CSS techniques — flexbox and CSS Grid, media queries, CSS variables, and transitions.

This is a frontend-only project (no backend, no JavaScript required for the core layout). It's great for practicing responsive design, CSS layout patterns, and for use as a portfolio piece.

## Usage

* Edit `index.html` to change content and structure.
* Modify `css/styles.css` to change visual styles and layout.
* Replace images in `assets/` with your own.

## Customisation

* Change the color scheme using CSS variables at the top of `styles.css`.
* Replace placeholder text and card images with real content.
* Add simple JavaScript if you want interactive behaviors (e.g., carousel, modal play trailer).

## Accessibility & Responsiveness

* Use semantic HTML tags (`header`, `nav`, `main`, `section`, `footer`).
* Provide `alt` text for images.
* Ensure color contrast is sufficient for text readability.
* Test with keyboard navigation and on multiple devices.
